Streamscope Netflix – Data Analysis Dashboard & Recommendation System
📌 Project Overview

Streamscope Netflix is an interactive data analysis dashboard built using Python and Streamlit to explore Netflix content trends and provide intelligent insights through data visualization and machine learning.

The project analyzes Netflix movies and TV shows dataset to uncover trends related to genres, ratings, countries, release years, and content growth. It also includes a basic recommendation system and machine learning models for predictive analysis.
